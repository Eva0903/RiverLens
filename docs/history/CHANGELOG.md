# Changelog

## 4.0.0

- 新增独立的 `06_lstm_upgrade`，保留 01–05 的完整可复现实现与既有论文主线。
- LSTM 改为预测 Persistence/24 h Seasonal naive 之上的残差，而不是直接拟合绝对浓度。
- 每个提前量的朴素锚点和残差门控系数只由验证集确定；门控为 0 时严格退回朴素预测。
- 新增本地目标、跨站同指标、过程聚焦与全站变量四组候选输入，并加入一阶差分与周期时间特征。
- 所有候选窗口和特征组在最长窗口、变量并集生成的同一时间样本上比较。
- 新增 Huber loss、AdamW、学习率衰减、梯度裁剪和小容量单层 LSTM。
- 最佳 epoch 由训练/验证早停确定，正式模型随后在训练集+验证集上按该 epoch 数重训。
- 新增 validation-only 选择配置、完整正式配置、候选排名、门控诊断和最终朴素技能检验。

## 3.0.0

- 主分析切换为因果缺失处理，目标评分保持原始观测。
- 新增 24 h Seasonal naive、MASE、nRMSE 与朴素基线技能分数。
- rolling-origin 改为每折独立预处理；窗口网格固定共同时间支持集。
- 新增漂移诊断、模型排名、随机拆分乐观偏差和运行状态输出。
- bootstrap p 值采用 add-one 校正。
- 强化 CUDA/PyTorch 确定性和环境记录。
- 引入配置指纹、`task_id` 完整性修复、损坏尾行恢复、跨进程锁、失败任务清单和安全断点续跑。
- 汇总表改为便于 Excel/R 读取的单层列名；图件完整显示负 R²。
