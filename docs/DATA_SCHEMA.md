# 本地数据接口

本说明描述现有读取器，不含任何真实观测示例。数据文件需自行获得合法访问权限。当前研究将A/B作为上游站、C作为下游目标站；05补充实验改变预测目标，但输入仍保留三站历史。

## 水质水文Excel

每份文件第一张工作表包含时间列与数值列。读取器按中文关键词识别数值列，不按Excel列位置读取。同一变量只保留一个可识别列，避免重名。

| 站点 | 文件名 | 必需时间列 |
|---|---|---|
| A | `station_A_Anshun.xlsx` | `监测时间_安顺廊桥` |
| B | `station_B_Chengren.xlsx` | `监测时间_成仁桥` |
| C | `station_C_Yongan.xlsx` | `监测时间_永安` |

| 变量识别关键词 | 代码名 | 当前输入位置 |
|---|---|---|
| 水温 | WT | A/B/C |
| pH | PH | A/B/C |
| 溶解氧 | DO | A/B/C |
| 电导率 | EC | A/B/C |
| 浊度 | TURB | A/B/C |
| CODMn | CODMN | A/B/C |
| 氨氮 | NH3N | A/B/C |
| 总磷 | TP | A/B/C |
| 流量 | FLOW | B |
| 总氮 | TN | C |

上述配置形成26列水质水文输入。四个预测目标为DO、NH3N、CODMN、TP。浓度数值采用原输入单位；研究图表中的四项预测指标以mg/L报告。电导率、浊度、流量等保持输入单位，文件应由数据提供者同时说明单位，不能自行假设换算。

## 小时气象Excel

文件名为`weather_hourly.xlsx`，时间列`DATETIME`。数值列必须包含：

| 列名 | 含义及读取规则 |
|---|---|
| PRE_1H | 小时降雨，按4小时累计；需要完整4小时记录 |
| PRS | 气压，4小时均值 |
| RHU | 相对湿度，4小时均值 |
| TEM | 气温，4小时均值 |
| WIN_D_INST_MAX | 风向角，转正弦/余弦后求4小时均值 |
| WIN_S_INST_MAX | 风速，取4小时最大值 |

小时数据按右闭合、右标签的4小时区间汇总。降雨衍生列包括4/8/12/24小时滞后以及12/24小时累计。完整联合输入为39列。

## 时间与缺失值

研究步长为4小时。观测时间按配置容差吸附至时间网格；重复时间点取均值。时间列应使用一致时区/本地时间约定，不应混用。短输入缺口按既定`causal_ffill`规则处理，评分目标保持原始观测，不以插补浓度替代。

不要为了适配新数据悄悄改变原实验配置后覆盖旧结果。新数据或配置应使用新的输出目录。

## 不使用真实数据的接口测试

所有标准单元测试在临时目录生成合成Excel。也可以显式生成到一个新的空目录：

```powershell
python scripts\make_synthetic_data.py --output data\synthetic_local
```

生成器拒绝覆盖同名文件；生成结果由Git排除。这些文件仅检查读取和运行通路，不能用于性能结论。
